## 5. Comparação entre planejado e realizado

As entregas de infraestrutura e do fluxo mínimo de relatos avançaram: a API está documentada, possui conexão PostgreSQL, validação básica do payload e foi compilada com sucesso. O histórico recente também registra a configuração do deploy e das variáveis de ambiente na Vercel/Supabase; essa informação é documental e não foi revalidada externamente neste acompanhamento.

Permanecem desvios relevantes em relação ao produto descrito no README e ao backlog:

- não há cadastro, login, autenticação ou autorização implementados;
- a consulta de relatos não possui controle de acesso;
- a validação atual não comprova limites de texto, URLs ou intervalo de coordenadas;
- não há testes automatizados nem teste de integração ponta a ponta;
- status, histórico de encaminhamento e responsável pelo acompanhamento do relato ainda não existem no modelo implementado.

## 6. Resultados e mudanças percebidas

- A implementação oficial do backend está documentada como Node.js/Express, reduzindo a ambiguidade anterior registrada no backlog.
- O fluxo mínimo de criação e consulta de relatos está representado na API e no modelo de domínio.
- A documentação de instalação descreve desenvolvimento local, deploy na Vercel, banco Supabase e variáveis de ambiente.
- A separação entre Android, frontend, admin, API e banco permanece visível na estrutura do repositório.
- Não foi possível confirmar neste ambiente a compilação do frontend, do admin ou do Android.

## 7. Riscos, desvios e impedimentos

| Risco ou impedimento | Impacto | Situação |
|---|---|---|
| Relatos consultáveis sem autenticação/autorização | Exposição potencial de dados sensíveis | Requer priorização P0 |
| Ausência de testes automatizados | Regressões podem não ser detectadas | Pendente |
| Regras de validação incompletas | Dados inválidos ou excessivos podem ser aceitos | Pendente |
| Frontend/admin sem dependências instaláveis neste ambiente | Build não verificado; `npm ci` encontrou `EACCES` em `node_modules` | Requer ajuste de permissões ou ambiente limpo |
| Android sem Android SDK configurado | `assembleDebug` não pôde concluir | Requer configurar `ANDROID_HOME` ou `local.properties` |
