# Planejamento da Sprint 3: Refinamento e Integração

## Objetivo
Polir a experiência do usuário, aprimorar a segurança do sistema e integrar fontes de dados externas para transformar o app em uma ferramenta de suporte abrangente.

## Backlog da Sprint

### 1. Polimento de UI/UX e Acessibilidade
- [ ] Refinar widgets personalizados para garantir interface humanizada e acolhedora.
- [ ] Otimizar layouts para responsividade em diferentes resoluções de Android.
- [ ] Implementar feedback visual (loaders, skeletons e mensagens de erro).

### 2. Funcionalidades Avançadas e Segurança
- [ ] Integrar `image_picker` para upload de evidências/documentos no chat.
- [ ] Reforçar a segurança do `flutter_secure_storage` para gestão de sessões.
- [ ] Implementar validações rigorosas em todos os formulários de entrada.

### 3. Integrações Externas e Inteligência de Dados
- [ ] Pesquisar e mapear dados de "Violência contra Mulheres" no Portal de Dados Abertos do Brasil.
- [ ] Mapear serviços do Gov.br para integração de links diretos de denúncia e suporte.
- [ ] Refinar a lógica de backend para gestão do ciclo de vida de um caso reportado.

## Critérios de Aceite
- A interface deve apresentar um nível de polimento profissional, com feedbacks claros para o usuário.
- O upload de imagens deve funcionar corretamente dentro do fluxo de chat.
- O sistema deve validar corretamente entradas de usuário, impedindo envios incompletos ou errôneos.
- Deve haver um plano de integração claro (ou protótipo) para os dados governamentais.
